2024 event-level lepton-removal closure

Component policy: Top = TT + ST. W→ℓν is the only separately moving target component.

Prototype scope: the event migration and shape are tested. The residual normalization α is derived from MC because an absolute lepton-loss efficiency payload is not yet available. The current one-lepton flat materialization also requires the original pTmiss to exceed 250 GeV, so migration from below that threshold is absent. Nominal SR data remain blinded.

Decision: do not adopt this monolithic four-vector-removal estimator. Only 1 of 5 data validation regions improves over the previous Top/W transfer-factor result, and the MC cross-fit fails the shape test despite its imposed integral normalization.
