# Early Run 3 inference inputs

`config.json` provides the score bins and model location for 2022, 2022EE,
2023 and 2023BPix. The trained weights are an internal dependency: use the
approved `gnn4lowdm/early_run3_2022/diagonal_v3_numpy.npz` from the managed
TROTASR analysis root at the same relative path. The weights and training
records are not distributed here; do not substitute the 2024/2025 model.
